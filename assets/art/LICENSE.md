# Original artwork

`keep.svg`, `grain.svg`, `bruiser.svg`, `rogue.svg`, `ranged.svg`, and the vector courtyard/miniature definitions are original artwork created for this project. No external textures were incorporated in this revision. The candidate Poly Haven Stone Floor texture (Dimitrios Savva, CC0; https://polyhaven.com/a/stone_floor) was not downloaded or distributed.

## Painted chassis (5.0.4)
`bruiser-painted.webp`, `rogue-painted.webp`, `ranged-painted.webp`: original concept images generated with OpenAI image generation for this project, approved by the project owner, then cropped, contrast-adjusted and resized to 96 × 112 transparent WebP for the game. Not represented as third-party CC0 artwork. No external textures are embedded in these derivatives.
