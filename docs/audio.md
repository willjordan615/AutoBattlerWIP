# Fantasy tabletop audio
The current combat palette uses CC0 fantasy game effects (Artisticdude, Delta12 and Kenney; see assets/audio/CREDITS.md). Four original procedural UI and transition clips are unchanged. Run node scripts/generate-audio.js only to regenerate those four. Music remains The Old Tower Inn (RandomMind, CC0), default 6%, with independent volume and toggle. Combat cues are provisional and require listening-based review; no audio from commercial games.
The semantic event adapter preserves chassis-specific release, actual contact/miss distinction, and the Hazardous variant. Dodge uses the miss texture rather than the Rogue attack. Reduce generic impact gain to .27 so it supports rather than dominates chassis cues. Six SFX voices, per-group cooldowns, three combat starts per 250ms, two groups per tick, cosmetic pitch/gain variation, native media fallback and Web Audio. Sound defaults combat 30%/interface 25%, existing preferences preserved. Local audio only, paused in background, no simulation changes.

Bruiser uses a heavy soft-material impact instead of a ringing hammer sample; other cues and mixing unchanged.
