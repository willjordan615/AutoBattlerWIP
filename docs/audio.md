# Quiet tabletop audio
Original offline-generated procedural audio: node scripts/generate-audio.js. Eleven mono 22.05kHz 16-bit PCM WAVs, seeded noise, damped resonances and bounded envelopes; no external samples or music. No synthesis work in gameplay. Distinct dense granular low-end Bruiser, broad noise-swept Rogue, string-like ranged, hollow airy Hazardous variant, impact, guard, utility, wood-like click/confirmation, restrained start/end tones. Semantic attackRelease events carry source identity, chassis and Hazardous flag. Select one variant per attack, not stacked overlay sounds; extend modifier mapping as useful. Audio no longer follows attackCommit during windup. The native Web Audio consumer and HTML media fallback retain default Combat 30% / Interface 25%, master .62 and per-cue attenuation, up to six voices, two distinct prioritized groups per tick, per-group cooldowns, three combat starts per rolling 250 ms per backend, per-playback variation on both backends (Bruiser ±10%, Rogue ±12%, other combat ±7.5% pitch/rate; combat gain 82–100% of nominal), stable UI tones (±2% pitch, 96–100% gain), and stereo placement where supported. Audio pauses in background and ignores paused steps, sped-up replay and online catch-up. Options includes per-cue audition selector. No music, continuous footsteps or DOT sounds; no engine RNG or rules changes. Playback activation and native fallback unchanged. Validate audible quality on devices.
