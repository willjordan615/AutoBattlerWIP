# Quiet tabletop audio
Native Web Audio consumer with HTML media fallback, independent of simulation. Ten local CC0 clips: weighty metal, short slice, dedicated game bow cue, soft impact, metallic guard, leather handling, wooden click and confirmation, book open/close for round transitions. Kenney and Battle Sound Effects (artisticdude/Ogrebane), see assets/audio/CREDITS.md. No synthetic interface bleeps, music, continuous footsteps or DOT sounds. Default Combat 30% / Interface 25% with master .62 and per-cue attenuation. Up to six voices, two distinct prioritized groups per tick, per-group cooldowns, max three combat starts per rolling 250 ms per backend. Quiet stereo placement where supported; restrained .97–1.03 playback rate. Up to .40s combat, .28s UI and .65s transitions; Web Audio fades the end of each clip. Native HTML audio uses short timed playback. Both modes share the same priority and voice limit. Context resume retries on trusted activations; preview reports playback/errors and uses native fallback when necessary. Suspends/stops when hidden or muted, ignores paused stepping, sped-up replays and Quick Play catch-up. Missing/unsupported audio is silent and never blocks game. Local preferences only. No simulation RNG or new telemetry. Validate audible quality and device performance in playtests.
