# 3.5 bot profile calibration

The 3.4 fitted model is the reference, not an optimum every bot must reach. Introduce eight style inclinations (versatile, mobile, durable, controller, selective, cooperative, wide coverage, adaptive) crossed with three independent skill levels, 24 possible profiles. Stable hash of match seed and seat selects style uniformly, skill at 25% casual / 50% regular / 25% experienced, no extra draft RNG. Each seat retains its profile through the match. Repeats allowed; continuous seeded variation remains. No fixed builds, no chassis or player-stat changes. All use learned card values; contextual coefficients (including pairs) retain 35%, 70%, or 100%, and bounded option noise is 8, 5, or 2.5 points respectively. These are provisional calibration settings, not measured difficulty levels. Explicit empirical policy preserves exact 3.4 behavior; branch default is profiled. Draft records include profile ID, style, skill. No extra simulations during live drafting.

Validation: four shards, 8 seeds each. For each seed rotate casual, regular, experienced, and unchanged 3.4 empirical reference through all four seats (128 matches), plus 32 random-profile lobbies. Measure wins/rank by skill and chassis, relative choice-score gaps under the full empirical model using same preferences (proxy only; not true outcome regret), non-best frequency, card distributions, profile representation, timeouts. Two scripted player games. Skill order should generally emerge in aggregate, not guarantee individual match outcomes. No optimization toward maximum global bot win rate. Keep 3.4 live pending verification. No new empirical training or game-rule changes. Main release regression fix scoped to old profile assertion; 3.4 Pages succeeded.
