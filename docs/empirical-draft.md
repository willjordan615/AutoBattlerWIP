# Empirical draft valuation

The runtime scorer uses a fitted sparse model derived from paired game outcomes. Do not add theoretical combination bonuses to production. The checked-in model is active; fitting a replacement in CI must not change it automatically. Refit after material rules changes and verify independently.

## Actual option trials

Collect last-picker boards from real games drafted under alternating profile/coherent source policies, every other round. At this point all opponents have drafted. Enumerate every remaining legal card/chassis/slot (deduplicate identical card assignments), and a no-pick counterfactual. For each option, replay the actual arena/spawn seed and a second arena/seed variant, keeping opposing rosters and focal pre-pick roster fixed. Rank through the actual game rules, including ties, and track player HP saved, rank utility (first=1, last=0), damage and timeouts. Compare the profile and coherent choices on identical boards; report disputed picks and their measured deltas. Neutral counterfactual intentionally skips a mandatory pick only for measuring marginal value, never changes real game rules.

Fit on 64 source matches across seeds 5101–5808 (8 shards of 8). Holdout 32 distinct source games 6101–6408; no fitting to these. Fit a sparse regularized linear model to paired normalized rank-utility deltas, each board equal weight, features derived from actual roster before/after assignment. Card, chassis, squad size, repeat, co-equipped pair and teammate features are descriptive, not manually assigned signs. All observed pairs eligible, require at least six distinct boards, penalize sparse interactions more strongly. Removed abilities generate negative features, recruitment includes changes in roster-size interactions. Coefficients can be negative. Runtime only predicts from compact sparse features; no rollouts on phone. Retain bounded personality preference (+/-3 score) alongside measured utility (40 points per unit), rather than legacy theoretical bonuses. Scale and regularization are explicit provisional choices. Validate on independent held-out option trials and 128 complete matches (64 mixed seat-swapped, 32 per homogeneous policy) from entirely separate seeds 6501–6808. Report outcome utility, HP saved, realized regret, actual game wins/rank, timeouts and personality influence. No automatic adoption: retain the current model until evidence supports committing the fitted replacement.

Limitations: immediate round rank is not full-match marginal value; last-picker boards underrepresent early contested choices; source distributions depend on existing policies; sparse combinations shrink to zero; repeated alternatives on a board and arena variants are not independent; model cannot establish causal interaction beyond tested alternatives. Match validation is necessary to check recruitment/long-horizon behavior. Keep gameplay, module and draft-pool rules fixed during the audit.
