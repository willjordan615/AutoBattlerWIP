## Inspection and hypotheses

- Six seeded continuous traits already exist (mobility, control, survival, focusFire, teamwork, coverage). New cards often lacked trait metadata; stronger but bounded alignment plus explicit missing-card traits should make profiles visible without forcing identical paths.
- Existing recruitment value barely accounts for actual base-stat loss or specialization. Estimate net roster base HP and raw output after the real squad penalty, reduce recruitment preference with established attack/target investments, allow enabling existing ally modules. This is a heuristic, not a battle forecast; count/role benefits remain.
- Existing weak replacement penalty ignores upgraded utility and combinations. Estimate sacrificed module via existing scorer on cloned un-equipped unit, subtract a portion plus upgrade cost. Do not prohibit sensible replacement.
- Precision's historical kill-priority pairing is inconsistent with healthy-target damage. Replace with Challenger relationship. Preserve other proven relationships; no automatic bonus for old single-module win correlations.
- Small priors for Range, Regeneration, Coordinated, Resolve, Bulwark and Hazardous, modest downweight for isolated Piercing/Area, from 3.2 paired audit. They predate current AI, are hypotheses not permanent ranks. Hybrid cards gain modest explicit credit; Guardian's post-3.3 win correlation is not treated as causal. Add cap awareness and limited context based on public opponent roster and ally toolkit.
- Existing scorer remains available as legacy control, same personality generator and seeded tie-noise. Candidate is default only on the audit branch. No simulation rollouts during draft or runtime dependencies.
- Existing player harness now lists only per-chassis legal picks and considers both utility replacement slots. Agent-facing scores use public context, not secret bot personality.

## Tests

Four seed shards 4101-4108, 4201-4208, 4301-4308, 4401-4408. Each seed uses four actual drafted matches: mixed 2:2 old/new, swapped old/new seats, all legacy, all candidate. All policies use 3.3 simulation; initial starts/seed matched, later offers and picks naturally diverge. 128 total complete games: 64 mixed, 32 each uniform. Each policy occupies every seat once per mixed pair; 128 mixed player entries per policy. Report wins, rank sum, starting chassis, recruitment timing/roster sizes, module picks, category distribution, utility replacement frequency, build Jaccard diversity, chosen personality contribution. Distinct counts and Jaccard are descriptive, not a guarantee of coherent strategy. Profile probe compares opposite trait extremes on identical legal boards (3 chassis × 3 squad sizes × 32 seeds = 288 boards per policy, 1728 trait contrasts per policy). Separate two explicit scripted player games through existing harness; trace artifacts, not live browser play. Full Node regression plus focused new tests. Do not change coefficients before verifying actual results. Preserve main and Pages until review.

Known limitations: no learned policy or retrospective self-training; no hidden future offers or simulated lookahead; raw capacity ignores synergy and positional performance, slot value is approximate. Fixed seed pairing does not freeze later offers because actual drafting affects RNG consumption and cooperative offer probability. Mixed win rates are comparative; homogeneous policy win rates are 25% by construction. Prior and synergy hypotheses should be revised using observed opportunity and behavior, not just wins.
